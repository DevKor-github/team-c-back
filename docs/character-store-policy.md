# 캐릭터 상점 획득 정책

캐릭터의 `requiredLevel`은 소유권을 자동 지급하는 값이 아니라 포인트 구매 자격을 여는 조건이다.
`price`는 구매 시 실제 차감되는 포인트다.

| 구분 | 캐릭터 | 획득 정책 |
| --- | --- | --- |
| 기본 제공 | 애기호랑이 | Lv.1 캐릭터. 모든 사용자가 기본 보유하며 포인트 차감 없음 |
| 레벨 + 포인트 | 꼬마·포동·학생·어른호랑이 | 지정 레벨 달성 후 각 가격만큼 포인트를 사용해 구매 |
| 포인트 | 피곤·과잠·로봇·천사·악마호랑이 | 별도 레벨 제한 없이 포인트로 구매 |

`OWNED`는 사용자가 해당 캐릭터를 소유한다는 뜻이고, `isEquipped`는 보유 캐릭터 중 현재 대표로
착용한 하나를 뜻한다. 보유했다고 자동 착용되지는 않는다.

상점은 미보유 캐릭터를 먼저 보여주고 보유 캐릭터를 하단으로 내린다. 각 그룹 안에서는
`Lv.1 → 요구 레벨 오름차순 → 포인트 전용 가격 오름차순`으로 정렬한다. 애기호랑이를 포함한
레벨 캐릭터에는 보유·구매 가능 여부와 관계없이 항상 `Lv.N` 배지를 표시한다.

기존 사용자에게 애기호랑이 보유 행이 없을 수 있으므로 `GET /api/store`와
`GET /api/store/my`가 최초 조회 시 누락된 기본 보유 행을 멱등 보정한다.
